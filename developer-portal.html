Developer portal

This portal offers read-only integration examples and a minimal ERC-20 ABI for interacting with the verified Delta Coin contract on Polygon.

Contract details

Contract: 0xB0cea145750E76Ccb24a0007206f2485dd5bf21a

Network: Polygon mainnet (chain ID 137)

RPC: https://polygon-rpc.com

Minimal ERC-20 ABI (read-only)

[
  'function name() view returns (string)',
  'function symbol() view returns (string)',
  'function decimals() view returns (uint8)',
  'function totalSupply() view returns (uint256)',
  'function balanceOf(address) view returns (uint256)'
]

Example: Read totalSupply (browser)

Use the public Polygon RPC endpoint and ethers.js. This is a read-only example and does not require private keys.

const provider = new ethers.providers.JsonRpcProvider('https://polygon-rpc.com');
const contract = new ethers.Contract('0xB0cea145750E76Ccb24a0007206f2485dd5bf21a', ABI, provider);
const total = await contract.totalSupply();
console.log(ethers.utils.formatUnits(total, decimals));

Note: Do not include private keys in frontend code. For server-side signed transactions, use secure environment variables and never publish private material in the repository.

Integration guidance

  • Prefer server-side verification for financial flows (webhook verification, invoice mapping).
  • Do not perform token transfers from a centralized wallet without proper security and legal review.
  • Use dedicated indexer APIs (Polygonscan, TheGraph, Covalent) for holder and historical analytics.

Developer portal

Guides for integrating with the Delta Coin (DLC) contract and reading on-chain data. This portal does not publish private keys or administrative endpoints.

Network & RPC

  • Network: Polygon PoS (Mainnet)
  • Chain ID: 137
  • Public RPC used for reads: https://polygon-rpc.com

Contract

Contract address: 0xB0cea145750E76Ccb24a0007206f2485dd5bf21a

Minimal ERC-20 interface (example):

[
  "function name() view returns (string)",
  "function symbol() view returns (string)",
  "function decimals() view returns (uint8)",
  "function totalSupply() view returns (uint256)",
  "function balanceOf(address) view returns (uint256)",
  "function transfer(address,uint256) returns (bool)"
]

Note: Do not call transfer/send tokens on behalf of users without explicit user action and appropriate UI prompts. Never request private keys or seed phrases.

Integration examples

Use ethers.js or web3 libraries to read contract data. Example (ethers.js):

const provider = new ethers.providers.JsonRpcProvider('https://polygon-rpc.com');
const token = new ethers.Contract(tokenAddress, ABI, provider);
const total = await token.totalSupply();

For write operations, always prompt users via their wallet provider (MetaMask, Trust Wallet). Do not implement custodial transfers in the frontend.

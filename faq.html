FAQ and help center

This page exists to answer common questions in a transparent way. It is intentionally framed around real, source-backed status information rather than investment or trading guarantees.

Frequently asked questions

What is Delta Coin (DLC)?

DLC is the token referenced in the project website and repository documentation on Polygon mainnet.

Is the token contract audited?

No formal smart-contract audit is claimed in this repository.

Can I buy DLC directly on the site?

The current front end shows a buy flow, but the repository does not contain an independently verified token delivery mechanism. Users should verify live network behavior before treating it as completed.

Is there a verified liquidity pool?

Not proven by the repository. The correct disclosure is: liquidity pool not yet verified.

Does the site promise profit or guaranteed returns?

No. It does not claim guaranteed returns, value support, or profit promises.

What is the current project status?

The website and public docs exist, but legal review, security verification, and launch readiness checks are still pending.

Support and usage notes

  • Use the wallet provider you trust and verify the target network before sending any funds.
  • Check live transaction receipts before assuming success.
  • Do not share private keys, recovery phrases, or secret wallet credentials.
  • Any external payment flow must be independently verified to ensure the final token or payout behavior is real.

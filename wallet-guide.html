Wallet connection guide

Connecting a wallet should be simple, but users must always verify the correct network and operating conditions. This page documents the minimum expectations for a safe wallet connection and a simple mobile redirect flow.

Supported wallet types

MetaMask

Desktop browser extension and mobile app support.

Trust Wallet

Mobile app compatibility and deep-link approach.

WalletConnect-compatible wallets

Supports wallets that expose a standard Web3 provider.

Required network

  • Network: Polygon mainnet
  • Chain ID: 137
  • RPC endpoint: https://polygon-rpc.com
If the wallet is not on Polygon, approval should be requested before switching or sending funds. Never approve or sign a transaction without understanding the transaction request.

Mobile redirect behavior

A mobile user who does not have a browser wallet installed should be redirected to a wallet app or app store page, rather than silently failing. The repository now contains a mobile-aware helper that detects mobile browsers and opens a wallet deep-link attempt when a provider is missing. 

const config = {
  metamask: { ios: 'metamask://', android: 'https://metamask.app.link/dapp/' + location.host + location.pathname },
  trust: { ios: 'https://link.trustwallet.com/open_url?coin_id=966&url=' + encodeURIComponent(window.location.href) }
};
